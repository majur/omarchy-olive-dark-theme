# Olive Dark for Omarchy Quattro

A dark olive theme for Omarchy 4 (Quattro).

## Install

```bash
omarchy-theme-install https://github.com/majur/omarchy-olive-dark-theme
```

The theme uses the Quattro `colors.toml` palette and Omarchy's generated theme templates. Olive backgrounds are included in `backgrounds/`.

## Palette

- Background: `#1e1e1e`
- Foreground: `#a7a7a7`
- Accent: `#82a966`
- Selection: `#3d4d35`
